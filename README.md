## PULSE

PULSE is a personal tracking PWA for organizing inventory, schedules, logs, cycles, reminders, adherence, and research routines.

### Product identity

**PULSE · SCIENCE BY HUGS**  
**Track. Measure. Evolve.**

PULSE extends **Blue Reactor** with cyan, teal, and violet biometric accents. Red remains reserved for semantic warnings and alerts.

### Platform

- Vite + TypeScript
- Dedicated Supabase backend
- Email/password authentication
- Row Level Security for personal data
- Installable PWA
- Push/reminder infrastructure
- Science By Hugs Blue Reactor v2 branding

### Scope

PULSE records and summarizes information entered by the user. It is a tracking and calculation tool and does not prescribe, recommend, or determine medical treatment or dosing.

### Development

```bash
npm install
npm run dev
npm run build
```

Never add service-role or secret keys to this repository. The browser uses only the appropriate publishable client configuration.

The canonical brand specification lives at `docs/brand/BLUE_REACTOR.md`.
